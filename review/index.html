조건 판정 검수

기록된 결정의 구제 조치와 모델이 제시한 같은 조치를 비교해, 두 조치의 실질 조건이 같은지 판정합니다.

받은 안내에 적힌 ID를 그대로 입력하세요. 문항 순서와 저장 위치가 이 ID로 정해집니다.

안내받은 비밀번호를 입력하세요. 검수 자료는 이 브라우저 안에서만 풀립니다.

자료 파일을 따로 받은 경우

받은 condition_review_packet.json 파일을 끌어다 놓거나 선택하세요.

다른 기기에서 내보낸 결과 파일이 있으면 함께 선택하세요. 같은 브라우저라면 자동으로 이어집니다.

자료 파일은 이 브라우저 안에서만 읽히며 어떤 서버로도 전송되지 않습니다. 판정은 이 브라우저에 자동 저장되고, 마칠 때 결과 내보내기로 받은 파일을 담당자에게 보내 주세요.

판정 기준

무엇을 판정하나요

  • 왼쪽은 기록된 결정의 조치, 오른쪽은 모델 응답에서 같은 조치로 대응된 조치입니다.
  • 두 조치의 실질 조건이 같은지만 판정합니다. 금액·산식과 적용 범위는 별도 항목이므로 여기서는 판단하지 않습니다. 다만 금액을 어떻게 산정할지 정하는 조건은 조건으로 봅니다.
  • 조건은 조치 카드의 '조건' 칸에 있지만, 조치 설명(내용)에 조건이 들어 있으면 그것도 함께 봅니다.
  • 자동 판정 결과는 제공하지 않습니다. 독립적으로 판단해 주세요.

실행 조건은 실질 차이가 아닙니다

  • 다음은 확정된 권리를 이행하는 절차로 봅니다: 결정 수락, 계좌 정보 제공, 물품 반환, 이미 지급했는지 확인, 권리 확정 후의 금액 계산, 세금 관련 서류, 계좌 정정 전 상환, 연락처 확인 등.
  • 이런 조건이 한쪽에만 있거나 표현이 달라도, 그것만으로는 '다름'이 아닙니다.

'다름'으로 보는 경우

  • 한쪽은 확정 지급인데 다른 쪽은 새로운 증빙을 내야 지급하는 경우 (권리 입증 조건의 추가·누락).
  • 조건의 대상·기간·기준이 달라 받을 수 있는 범위나 산정 방식이 실제로 바뀌는 경우.
  • 조건부 권리의 성립 조건 자체가 다른 경우.

그 밖에

  • 문구 차이 자체는 차이가 아닙니다.
  • 조건 유형 표시(실행·권리 입증 등)가 달라도 내용이 같다면 '같음'으로 보고, Q2에서 '유형 표시만 다름'을 고르세요.
  • 두 조치가 애초에 같은 조치로 보기 어렵거나 기록된 결정 쪽 내용이 의심스러우면 Q4에 표시하세요. 이때 '판단 불가'를 골라도 됩니다.
  • 단축키: 1·2·3 = Q1 선택, ← → = 이동, Enter(메모 밖) = 저장하고 다음.
