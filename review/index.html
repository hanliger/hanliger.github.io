조건 판정 검수

기록된 결정의 구제 조치와 모델이 제시한 같은 조치를 비교해, 두 조치의 실질 조건이 같은지 판정합니다.

받은 안내에 적힌 ID를 그대로 입력하세요. 문항 순서와 저장 위치가 이 ID로 정해집니다.

안내받은 비밀번호를 입력하세요. 검수 자료는 이 브라우저 안에서만 풀립니다.

자료 파일을 따로 받은 경우

받은 condition_review_packet.json 파일을 끌어다 놓거나 선택하세요.

다른 기기에서 내보낸 결과 파일이 있으면 함께 선택하세요. 같은 브라우저라면 자동으로 이어집니다.

자료 파일은 이 브라우저 안에서만 읽히며 어떤 서버로도 전송되지 않습니다. 판정은 이 브라우저에 자동 저장되고, 마칠 때 결과 내보내기로 받은 파일을 담당자에게 보내 주세요.

1. 이 검수에 대하여

  • 자동 평가에서 내린 조건 판정을 사람이 다시 확인하는 검수입니다. 각 문항은 기록된 결정의 구제 조치 하나와, 모델 응답에서 그와 같은 조치로 대응된 조치 하나로 이루어집니다.
  • 문항은 150개입니다. 문항당 2–3분, 전체 5–7.5시간 정도 걸립니다. 한 번에 끝낼 필요 없이 여러 번 나누어 진행하면 됩니다.
  • 같은 사례가 여러 문항에 나올 수 있습니다. 문항마다 서로 다른 모델 응답이므로, 앞 문항의 판단을 가져오지 말고 각각 판단해 주세요.
  • 자동 평가의 판정은 보여 드리지 않습니다. 화면의 자료만으로 독립적으로 판단해 주세요.

2. 진행 방법

  1. 시작 화면에서 안내받은 검수자 ID와 비밀번호를 입력합니다. 문항 순서와 저장 위치가 ID별로 정해지므로, 매번 같은 ID를 입력해 주세요.
  2. 각 문항에서 두 조치를 비교하고 Q1–Q5에 답합니다.
  3. 저장하고 다음을 누르면 다음 문항으로 넘어갑니다. 위쪽 목록에서 원하는 문항으로 바로 이동할 수 있고, 미완료만을 켜면 남은 문항만 보입니다.
  4. 모든 문항을 마치면 결과 내보내기로 받은 파일을 담당자에게 보내 주세요.

3. 화면 읽는 법

  • 왼쪽(보라색)은 기록된 결정의 조치, 오른쪽(청록색)은 모델 응답의 조치입니다.
  • 각 카드에는 조치 종류, 내용, 당사자(누가 → 누구에게), 지위(현재 의무/조건부 권리), 금액, 관련 청구, 조건이 있습니다. 조건 앞의 꼬리표(실행·이행, 권리 입증, 금액 산정, 기타)는 각 쪽이 붙인 분류입니다.
  • 아래의 펼침 칸에서 사례 입력(청구·당사자 주장·경과)과 양쪽의 전체 조치 목록을 볼 수 있습니다. 비교 중인 조치는 강조 표시됩니다. 조건의 뜻이 분명하지 않을 때 참고하세요.
  • 원문은 영어이며, 화면의 항목 이름만 한국어로 바꿨습니다.

4. 질문별 답하는 법

Q1. 두 조치의 실질 조건이 같습니까?

  • 같음: 아래 판정 기준에 따라 실질적인 조건 차이가 없습니다.
  • 다름: 실질적인 조건 차이가 하나 이상 있습니다.
  • 판단 불가: 자료만으로는 판단할 수 없습니다. 이것도 정식 답변이며, 억지로 같음이나 다름을 고를 필요는 없습니다. 메모에 이유를 적어 주세요.

Q2. 관찰한 차이: Q1의 답과 관계없이, 두 조치의 조건을 비교하며 본 것을 모두 고릅니다.

  • 차이 없음: 표현만 다르고 내용은 같습니다.
  • 실행·이행 절차 성격: 한쪽에만 있는 조건이 확정된 권리를 이행하는 절차에 해당합니다.
  • 권리 입증 조건: 새 증빙을 내야 받을 수 있다는 조건이 한쪽에만 있습니다.
  • 금액 산정 조건: 금액을 어떻게 산정할지에 관한 조건이 다릅니다.
  • 대상·기간·기준이 다름: 양쪽에 조건이 있지만 내용이 다릅니다.
  • 유형 표시만 다름: 조건 내용은 같고 꼬리표(분류)만 다릅니다.
  • 기타: 위에 없는 경우입니다. 메모에 설명해 주세요.

Q3. 확신도: 본인 판정에 대한 확신 정도입니다.

Q4. 문제 표시: 해당할 때만 표시합니다.

  • 같은 조치로 보기 어려움: 두 조치가 애초에 같은 조치로 대응될 만하지 않다고 보는 경우입니다.
  • 기록된 결정 쪽에 의문: 왼쪽 조치의 내용이나 조건이 사례 자료와 맞지 않아 보이는 경우입니다.

Q5. 근거 메모: 한두 문장으로 판정 근거를 적어 주세요. 다름과 판단 불가에는 필수입니다.

5. 판정 기준

자동 평가에 적용된 코딩 규칙(v1)을 요약한 것입니다.

판정 대상

  • 두 조치의 실질 조건이 같은지만 판정합니다. 금액·산식과 적용 범위는 별도 항목이므로 여기서는 판단하지 않습니다. 다만 금액을 어떻게 산정할지 정하는 조건은 조건으로 봅니다.
  • 조건 칸 외에 조치 내용 안에 조건이 들어 있으면 그것도 함께 봅니다.

실행 조건은 실질 차이가 아닙니다

  • 다음은 확정된 권리를 이행하는 절차로 봅니다: 결정 수락, 계좌 정보 제공, 물품 반환, 이미 지급했는지 확인, 권리 확정 후의 금액 계산, 세금 관련 서류·통지, 계좌 정정 전 상환, 연락처 확인 등.
  • 이런 조건이 한쪽에만 있거나 표현이 달라도, 그것만으로는 '다름'이 아닙니다.

'다름'으로 보는 경우

  • 한쪽은 확정 지급인데, 다른 쪽은 새로운 증빙을 내야 지급하는 경우.
  • 조건의 대상·기간·기준이 달라 받을 수 있는 범위나 산정 방식이 실제로 바뀌는 경우.
  • 조건부 권리의 성립 조건 자체가 다른 경우.

그 밖에

  • 문구 차이 자체는 차이가 아닙니다.
  • 조건의 꼬리표가 달라도 내용이 같으면 '같음'입니다.

6. 저장과 제출

  • 답을 고를 때마다 이 브라우저에 자동 저장됩니다. 같은 브라우저에서 같은 ID로 다시 접속하면 이어서 할 수 있습니다.
  • 다른 기기에서 이어 하려면, 먼저 쓰던 기기에서 결과 내보내기로 파일을 받은 뒤 새 기기의 시작 화면에서 이전 결과 이어서 하기로 그 파일을 선택하세요.
  • 브라우저 기록을 지우거나 시크릿 창을 쓰면 저장이 사라질 수 있습니다. 중간중간 결과 내보내기로 파일을 받아 두시길 권합니다.
  • 모두 마치면 결과 내보내기로 받은 JSON 파일을 담당자에게 보내 주세요. CSV는 확인용입니다.
  • 제출 기한은 담당자의 안내를 따릅니다.

7. 지켜 주실 것

  • 독립적으로 판정해 주세요. 검수가 끝날 때까지 다른 검수자와 개별 문항의 판정을 이야기하지 말아 주세요. 기준 해석에 대한 질문은 담당자에게 해 주세요.
  • 화면에 제공된 자료만으로 판단해 주세요. 원 결정문이나 다른 평가 기록을 찾아보지 말아 주세요.
  • 자료와 비밀번호는 외부에 공유하지 말아 주세요.
